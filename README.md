## 📌 Project Overview
This repository contains the interactive engineering showcase application built to present full-scale technical contributions, architectural designs, and AWS cloud deployment achievements to company leadership.

The core application automates motor insurance claims processing, multimodal AI document extraction, bilingual driver question examinations, and statutory Word report compilation.

## 🛠️ Local Development

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
npm install
```

### Run Dev Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build Production Bundle
```bash
npm run build
```
